Gue software engineer dari Indonesia, sekarang kerja sebagai System Development Staff di **Thamrin Group**. Udah bikin-bikin barang buat web dan mobile dari tahun 2020 — mulai dari Flutter buat mobile apps, terus merambah ke ekosistem React/Next.js buat web development.

## Apa yang Gue Kerjain

Sebagian besar kerjaan gue di frontend — ngeubah design jadi interface yang berfungsi, bikin sistem komponen, dan mastiin kode tetep maintainable seiring project berkembang. Gue juga sesekali nyemplung ke backend pake Laravel, Express.js, dan PostgreSQL kalo emang dibutuhin.

Gue peduli soal **kualitas kode dan maintainability**. Udah pernah nge-refactor codebase lama, migrasi JavaScript ke TypeScript, dan adopt struktur project yang lebih baik. Nggak karena ikut-ikutan tren, tapi karena ada orang (seringkali gue di masa depan) yang harus kerja sama kode ini nantinya.

## Project yang Pernah Gue Garap

Beberapa highlight dari portfolio gue:

- **Taniyuk** — Platform web buat transparansi penjualan karet petani Indonesia. Gue handle frontend-nya sebelum di-handoff di 2024.
- **My PIM Club** — Aplikasi loyalty buat pelanggan Palembang Indah Mall, dibikin pake Flutter.
- **Laksa Online** — Aplikasi web buat jadwal kunjungan di Lembaga Pemasyarakatan Indonesia.
- **Eliteguard** — Sistem absensi mobile/web buat satpam.

Kebanyakan project gue melayani komunitas Indonesia — petani, mall, universitas, lapas. Gue suka bikin barang yang solve masalah nyata buat orang-orang nyata.

**Frontend:** React, Next.js, TypeScript, Tailwind CSS, Astro
**Mobile:** Flutter, Dart
**Backend:** Laravel, Express.js, Node.js

Gue selalu explore tools dan framework baru, tapi lebih milih depth daripada breadth. Teknologi terbaik adalah yang solve masalah tanpa bikin masalah baru.
